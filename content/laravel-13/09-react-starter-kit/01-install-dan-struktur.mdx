Di modul sebelumnya tampilan dibuat dengan Blade. Modul ini memakai jalur lain: **Laravel 13 React Starter Kit**, lengkap dengan auth, verifikasi email, dan satu CRUD.

Stack yang dipakai starter kit:

- Laravel 13
- React 19 dan Inertia v3
- TypeScript
- Tailwind v4 dan shadcn/ui
- Wayfinder (route yang diketik, jadi fungsi TypeScript)
- Laravel Fortify (auth)

Contoh CRUD-nya adalah **Task**, yaitu to-do per user. Polanya sama untuk model lain, tinggal ganti nama dan kolom (misalnya `Product`, `Book`, atau `Item`).

> Nama file dan folder bisa sedikit berbeda antar versi starter kit. Kalau ada yang tidak ketemu, cari dengan `ls` atau `grep`.

## Install project

Prasyarat: PHP 8.3+ (disarankan 8.5), Composer, Node.js 20+, dan Laravel Installer (`composer global require laravel/installer`).

```bash
laravel new task-app
```

Pilih saat wizard:

- Starter kit: **React**
- Authentication: **Laravel's built-in authentication** (Fortify). Jangan pilih WorkOS.
- Testing: Pest (bebas)

```bash
cd task-app
composer run dev
```

Buka `http://localhost:8000`. `composer run dev` menjalankan server Laravel, queue, dan Vite sekaligus. Wayfinder otomatis meng-generate helper TypeScript selama Vite berjalan.

│   ├── web.php

└── resources/js/
    ├── pages/

    └── routes/                     # (generated) Wayfinder dari named route

## Di mana logic auth?

Route login dan register tidak ada di `routes/web.php` karena didaftarkan otomatis oleh Fortify.

| Lokasi | Isinya |
|---|---|
| `app/Actions/Fortify/CreateNewUser.php` | Validasi dan pembuatan user saat register |
| `app/Actions/Fortify/ResetUserPassword.php` | Logic reset password |
| `app/Providers/FortifyServiceProvider.php` | Konfigurasi pusat: view Inertia untuk login/register, rate limiter |
| `config/fortify.php` | Fitur yang aktif |
| `app/Http/Controllers/Settings/*` | Update profile, password, 2FA |
| `routes/settings.php` | Route halaman settings |
| `app/Http/Middleware/HandleInertiaRequests.php` | Membagikan `auth.user` ke React |
| `resources/js/pages/auth/*` | Tampilan login, register, dll |

Aturan praktisnya: kalau mau mengubah **perilaku** auth, edit di backend. Kalau mau mengubah **tampilan**, edit di `resources/js/pages/auth/`. Validasi dan keamanan selalu dijalankan di backend.

Contoh perubahan umum:

- Tambah kolom saat register (misalnya `phone`): edit migration `users`, `CreateNewUser.php`, dan form register.
- Ubah aturan password: edit validasi di `CreateNewUser.php` dan `ResetUserPassword.php`.
- Ubah batas percobaan login: rate limiter di `FortifyServiceProvider.php`.
