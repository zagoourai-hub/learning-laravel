## Di mana aturan validasi berada

| Alur | Tempat aturan |
|---|---|
| Products | `app/Http/Requests/` (`StoreProductRequest`, `UpdateProductRequest`) |
| Register, update profile (name, email) | `app/Concerns/ProfileValidationRules.php` |
| Register, reset password (password) | `app/Concerns/PasswordValidationRules.php` |
| Login | Bawaan Fortify di `vendor/` (hanya required dan string) |

`CreateNewUser` dan `ProfileUpdateRequest` memakai trait di atas, jadi **ubah trait-nya, bukan dua file itu**.

## Aturan nama

```php
// app/Concerns/ProfileValidationRules.php
protected function nameRules(): array
{
    return ['required', 'string', 'min:3', 'max:255', "regex:/^[\pL\s\.\'-]+$/u"];
}
```

Pesan regex dalam bahasa Indonesia di `lang/id/validation.php`:

```php
'custom' => [
    'name' => [
        'regex' => 'Nama hanya boleh berisi huruf, spasi, titik, apostrof, dan tanda hubung.',
    ],
],
```

Gabungkan dengan key `custom` yang sudah ada kalau ada, jangan buat dobel.

## Aturan password

`passwordRules()` sudah memakai `Password::default()`, jadi kekuatannya diatur satu kali:

```php
// app/Providers/AppServiceProvider.php
use Illuminate\Validation\Rules\Password;

Password::defaults(fn () => Password::min(8)->letters()->mixedCase()->numbers());
```

Cek apakah starter kit sudah punya `Password::defaults(...)` di salah satu provider. Kalau ada, ubah yang itu, jangan menambah yang kedua (yang terakhir dipanggil yang menang):

```powershell
Select-String -Path app/Providers/*.php -Pattern "Password::defaults"
```

## Petunjuk password saat mengetik

Here's your complete `resources/js/components/password-hint.tsx`:

```tsx title="resources/js/components/password-hint.tsx"
import { CheckCircle2, Circle } from 'lucide-react';

type Props = {
    value: string;
};

const rules = [
    { label: 'Minimal 8 karakter', test: (v: string) => v.length >= 8 },
    { label: 'Ada huruf besar', test: (v: string) => /[A-Z]/.test(v) },
    { label: 'Ada huruf kecil', test: (v: string) => /[a-z]/.test(v) },
    { label: 'Ada angka', test: (v: string) => /\d/.test(v) },
];

export default function PasswordHint({ value }: Props) {
    return (
        <ul className="space-y-1 text-xs">
            {rules.map((rule) => {
                const ok = rule.test(value);

                return (
                    <li
                        key={rule.label}
                        className={ok ? 'flex items-center gap-1.5 text-green-600' : 'flex items-center gap-1.5 text-muted-foreground'}
                    >
                        {ok ? <CheckCircle2 className="size-3.5" /> : <Circle className="size-3.5" />}
                        {rule.label}
                    </li>
                );
            })}
        </ul>
    );
}
```

Pakai di `register.tsx`:

```tsx
const [password, setPassword] = useState('');

<Input id="password" type="password" name="password" required onChange={(e) => setPassword(e.target.value)} />
<PasswordHint value={password} />
```

Aturan di `rules` harus sama dengan `Password::defaults()`. Validasi server tetap yang utama, karena validasi client bisa dilewati.
